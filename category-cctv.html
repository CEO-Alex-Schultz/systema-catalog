О направлении Оборудование Детали

Четкое изображение и контроль входа на объект

Камера должна передавать лица, а не размытые пятна. Турникет должен пропускать сотрудников по карте без очередей. Мы выстраиваем системы так, чтобы они стабильно работали каждый день.

Решение под ваш объект

Офис, склад, магазин или парковка. Рассчитываем необходимое количество камер и места их установки, чтобы исключить слепые зоны.

Без лишних затрат

Не предлагаем дорогостоящие камеры там, где достаточно более простых моделей. Разницу наглядно показываем на примерах.

Монтаж своими силами

Прокладываем кабель, устанавливаем камеры и турникеты, настраиваем запись и права доступа. Предоставляем гарантию и остаемся на связи после сдачи объекта.

Краткие рекомендации по выбору

Объясняем без сложной терминологии и подскажем оптимальный вариант для ваших задач.

Камеры Разрешения 2 Мп достаточно для общего плана, при 4 Мп уже различимы лица. Для улицы выбираем модели со степенью защиты IP67 и подсветкой. Купольные камеры подходят для помещений, цилиндрические для уличной установки.
Запись Регистратор NVR принимает и записывает видео с IP камер. Для 8 камер обычно хватает диска объемом 4-6 ТБ при хранении записей в течение двух недель. Возможна запись в облако.
Просмотр Доступен с телефона и компьютера через приложение. Доступ можно предоставить службе охраны и руководителю. Запись по движению позволяет экономить место на диске.
СКУД Идентификация по картам или брелокам, а также по отпечатку пальца или лицу. Контроллер на 1-2 двери подходит для офиса, системы на большое число дверей для производственных объектов. Журнал событий ведется в программе.
Турникеты Трипод подходит для стандартной проходной, распашной вариант для проезда колясок и грузов. Устанавливаем вместе со СКУД, чтобы карты работали на всех точках прохода.
Кабель и питание Витая пара на расстояние до 100 метров, питание по PoE через один кабель. Для улицы применяем специальный уличный кабель. Все линии аккуратно прокладываем в коробах.
Документы Предоставляем кассовые чеки и гарантийные документы, а также помогаем с подготовкой технического задания для закупок по 44-ФЗ и 223-ФЗ.
